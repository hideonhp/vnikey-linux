# Security Policy / Chính sách bảo mật

## Supported Versions / Các phiên bản được hỗ trợ
Only the latest version of `vnikey-linux` receives security updates.
Chỉ phiên bản mới nhất của `vnikey-linux` nhận được các bản cập nhật bảo mật.

| Version / Phiên bản | Supported / Được hỗ trợ |
| ------------------- | ------------------ |
| `main` (Latest)     | ✅                 |
| Older / Cũ hơn      | ❌                 |

---

## Reporting a Vulnerability / Báo cáo lỗ hổng bảo mật

**Please do not report security vulnerabilities through public GitHub issues.**
**Vui lòng không báo cáo các lỗ hổng bảo mật thông qua tab Issues công khai.**

If you discover a security vulnerability within `vnikey-linux`, please report it privately. You can reach out via:
Nếu bạn phát hiện ra lỗ hổng bảo mật trong `vnikey-linux`, vui lòng báo cáo riêng tư qua:

* **Email:** [Điền email của Sếp vào đây, ví dụ: your-email@domain.com]
* **GitHub Security Advisories:** Use the "Report a vulnerability" option in the **Security** tab of this repository. / Sử dụng tùy chọn "Report a vulnerability" trong tab **Security** của kho mã nguồn này.

### What to include in your report / Nội dung cần cung cấp:
* Type of vulnerability (e.g., buffer overflow, memory corruption). / Loại lỗ hổng.
* Full paths of source file(s) related to the vulnerability. / Đường dẫn file liên quan.
* Step-by-step instructions to reproduce the issue. / Các bước chi tiết để tái hiện lỗi.

We appreciate your effort to responsibly disclose vulnerabilities and keep `vnikey-linux` safe for everyone! 🛡️
Chúng tôi đánh giá cao nỗ lực tiết lộ lỗ hổng có trách nhiệm của bạn để giữ an toàn cho `vnikey-linux`! 🛡️
