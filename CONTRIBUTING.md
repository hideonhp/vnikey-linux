# Contributing to vnikey-linux / Hướng dẫn đóng góp cho vnikey-linux

First off, thank your for taking the time to contribute! 🎉 
Trước hết, cảm ơn bạn đã dành thời gian để đóng góp cho dự án! 🎉

---

## 🧭 Code of Conduct / Quy tắc ứng xử
Be respectful, constructive, and welcoming to everyone in this community.
Hãy tôn trọng, mang tính xây dựng và cởi mở với mọi người trong cộng đồng này.

---

## 🚀 How to Contribute / Cách thức đóng góp

### 1. Reporting Bugs / Báo cáo lỗi
* Use the **Issues** tab to report bugs. / Sử dụng tab **Issues** để báo lỗi.
* Provide clear steps to reproduce, along with your Linux distribution, desktop environment (GNOME, KDE, etc.), and input method (Telex/VNI). / Cung cấp các bước tái hiện rõ ràng kèm theo thông tin phân phối Linux, môi trường desktop và kiểu gõ.

### 2. Suggesting Features / Đề xuất tính năng
* Open a thread in the **Discussions** tab for brainstorming and community feedback before writing code. / Mở một chủ đề trong tab **Discussions** để thảo luận và nhận phản hồi từ cộng đồng trước khi bắt tay viết code.

### 3. Pull Requests / Gửi mã nguồn (PR)

   git checkout -b feature/your-feature-name
